# 🧹 CleanCampus

### 🌱 A Digital Initiative for a Cleaner and Greener Campus

**CleanCampus** is a web-based project designed to promote cleanliness, hygiene, waste management, and environmental awareness within educational campuses.

The project provides an attractive and simple interface to spread awareness about maintaining a clean campus and encouraging students to participate in cleanliness activities.

## 📌 Project Overview

Cleanliness is an important part of creating a healthy, safe, and sustainable educational environment.

The **CleanCampus** project aims to create awareness among students and campus communities about:

* 🗑️ Proper waste disposal
* ♻️ Waste segregation and recycling
* 🌱 Environmental sustainability
* 🧼 Campus hygiene
* 🚯 Avoiding littering
* 🌍 Responsible use of natural resources
* 🤝 Student participation in cleanliness activities

The website presents these ideas through a user-friendly and visually appealing web interface.

---

## 🎯 Objectives

The main objectives of this project are:

1. To promote cleanliness and hygiene on campus.
2. To create awareness about proper waste management.
3. To encourage students to avoid littering.
4. To promote the **Reduce, Reuse and Recycle** concept.
5. To encourage responsible environmental behavior.
6. To support the vision of a clean and sustainable campus.
7. To provide an accessible digital platform for cleanliness awareness.

## 🚀 How to Run the Project Locally

### Step 1: Clone the Repository

```bash
git clone https://github.com/daradhya003-hub/Cleancampus.git
```

### Step 2: Open the Project

```bash
cd Cleancampus
```

### Step 3: Open `index.html`

You can simply open:

```text
index.html
```

in a web browser.

### Recommended

If you are using **Visual Studio Code**, install the **Live Server** extension and open the project using Live Server.

## 💻 Development Using VS Code

1. Install Visual Studio Code.
2. Clone or download the project.
3. Open the `Cleancampus` folder in VS Code.
4. Open `index.html`.
5. Edit HTML, CSS and JavaScript files.
6. Run the website using Live Server.
7. Test the website in a browser.
8. Commit your changes to GitHub.
